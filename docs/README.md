# Documentation Index

This folder contains technical documentation for the Atlanta Namadwaar Home Program Booking app.

## Documents

- `AUDIT.md`: Code quality audit findings, cleanup actions, and remaining risks.
- `ARCHITECTURE.md`: System design, state model, routing, and functional behavior.
- `FLOWS.md`: End-to-end user and API flows for booking and reservation management.
- `SETUP_AND_OPERATIONS.md`: Local setup, environment variables, scripts, and deployment notes.
- `FILE_REFERENCE.md`: File-by-file reference for all code/config files in the repository.
- `MOBILE_APP.md`: Native mobile app architecture, setup, Android APK testing, and iOS TestFlight release path.
