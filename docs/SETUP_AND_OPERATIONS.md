# Setup And Operations

## Prerequisites

- Node.js 18+ (recommended modern LTS)
- npm

## Install

```bash
npm install
```

## Environment Variables

Configured via `.env`/`.env.local`:

- `VITE_API_BASE`
  - Base URL for booking/reservation backend APIs.
  - Defaults to production service URL if unset.
- `VITE_GOOGLE_MAPS_API_KEY`
  - Required for booking-form address autocomplete.

## Scripts

- `npm run dev`
  - Starts Vite dev server.
- `npm run build`
  - Regenerates program image manifest, then builds production bundle.
- `npm run preview`
  - Serves built assets locally.
- `npm run typecheck`
  - Runs TypeScript compile checks (`tsc --noEmit`).
- `npm run check`
  - Runs `typecheck` then `build`.

## Generated Files

- `generated/programImageManifest.ts`
  - Auto-generated by `scripts/generateProgramImageManifest.mjs`.
  - Do not edit manually.

## Deployment Notes

- Base route is `/homebookings/`; keep this aligned with hosting config.
- `public/.htaccess` includes Apache rewrite and cache headers.
- App expects API endpoints at:
  - `POST /api/bookings`
  - `POST /api/reservations/verify`
  - `POST /api/reservations/update`
  - `POST /api/reservations/delete`
